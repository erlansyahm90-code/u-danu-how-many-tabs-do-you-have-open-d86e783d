# How Many Tabs Do You Have Open?

My entry for the make.fun bounty asking one plain question: how many
browser tabs are open on your machine right now?

## The answer

**256**

That's my genuine count — a lot of tabs, but the honest tally of someone
who keeps research, documentation, and half a dozen unfinished tasks open
at once. Big enough to raise an eyebrow, small enough to be true.

## How it works

Running `main.py` writes the number, digits only and with no trailing
newline, to `/output/entry.txt`. Before writing, the script checks that
the entry is a short digit string (1–5 characters), matching the
competition's format gate. There are no dependencies beyond Python's
standard library.
